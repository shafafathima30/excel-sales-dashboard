# E-Commerce Sales Analysis Dashboard

## Project Overview
An Excel-based sales analysis project using the Global Electronics Retail dataset to explore sales performance, profitability, product performance, and customer demographics.

## Tools Used
- Microsoft Excel 2016
- Power Query
- Pivot Tables
- Pivot Charts
- Excel formulas

## Dashboard Highlights
- Total Revenue and Total Profit KPIs
- Revenue and Profit by Country
- Top 10 Products by Revenue
- Customer Count by Age Group and Gender
- Customer Count by Country
- Customer Count by Continent

## Key Skills Demonstrated
- Data cleaning and preparation
- Exploratory data analysis
- KPI analysis
- Data visualization
- Business reporting
